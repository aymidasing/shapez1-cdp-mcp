# 建筑、连接和一条满带

下表按 Steam 1.5.6 原版建筑编号编排。端口以旋转 0° 为准，北在上。南入代表接收南侧相邻格送来的物料。先用 `game {"op":"catalog","id":"painter","rotation":90}` 查具体格、方向和接收类型。实际建成后用 `building` 查世界坐标。regular 和 wires 各占一层，普通机器的信号脚伸到 wires 层。

## 物料层

台数按运输、开采、加工和上色倍率相同、原料持续供应、全部出口可排空计算。加工组按一条图形输入带设计；堆叠和调色要另配第二条原料带。不同升级倍率时直接读 `speeds.fullBelt`，通式是向上取整「目标带速 ÷（机器每游戏秒循环数 × 每循环目标件数）」。切割机排出多个不同部件，要按各自出口算带宽。

| 编号与建筑 | 旋转 0° 的输入、输出及效果 | 线路与配比 |
| --- | --- | --- |
| 1–3 传送带 belt | 南入。1 北出直行，2 西出左弯，3 东出右弯。单格只有一个固定入口和出口。东行后向北时，拐点取“西入北出”，其前后仍是两段有向直带。 | 无线，一条线承载一条带。连续路径用 route，端点也占格。 |
| 4 均衡器 balancer | 南侧两个口入，北侧两个口均分；任一端堵塞时可走另一可用端。 | 无线。一台可连接两带进、两带出。 |
| 5/6 合流，47/48 分流 | 5 南和东入、北出；6 侧口在西。47 南入、北和东出；48 侧口在西。 | 无线。一条公共带限制总流量，合流前两支路应按份额供货。 |
| 7/8 开采器 miner | 放在图形或颜料矿上，北出。8 链式可把产物沿朝向传给紧邻的链式开采器，由链尾出带。 | 无线。同倍率 5 台供满一带。严格同一资源时先按 ground 查每个矿格。 |
| 9 二切 / 10 四切 cutter | 南侧第一个口进图形，顶部依次出两半或四个象限。四切出口从左到右为右上、右下、左下、左上。空象限无产物。 | 无线。两种均 4 台消化一条输入带；每种非空片可各满一带。接走或丢弃用不到的切片。 |
| 11/12/13 旋转器 rotater | 南进图形，北出；分别顺时针 90°、逆时针 90°、180°。 | 无线。每种 1 台。 |
| 14 堆叠机 stacker | 两个南口，左口为底、右口为上；北侧左口出。局部象限会按游戏碰撞规则落层，最多保留四层。 | 无线。8 台，两条输入带各一件，产一条成品带。 |
| 15 混色器 mixer | 两个南口各进一份颜色，北侧左口出一份混色。红绿得黄，绿蓝得青，蓝红得品红，补色叠加得白。 | 无线。5 台，两带颜料入、一带颜料出。 |
| 16/17 普通、镜像上色 painter | 西进图形，东出成品。颜料从右格的北侧进，镜像从南侧进。 | 无线。6 台，一带图形加一带颜料。 |
| 18 双重上色 painter double | 西侧上下两个图形口，加右上格北侧一份颜料；从东口排出两个成品。 | 无线。4 台产一带成品；图形总量一带，颜料半带，两个图形口均需供料。 |
| 19 四色上色 painter quad | 西进图形，左端北出。南侧四个颜料口分别配同格的使能脚，依次对应右上、右下、左下、左上。 | **需信号**。至少一个使能脚为真，启用的象限供对应颜料，关闭的保留原色。2 台；每个持续启用的象限各需一满带颜料。 |
| 20 垃圾桶 trash | 四边接收并销毁物品，无出口。 | 无线，一台可消耗输入带，用于切割余料。 |
| 21 仓库 storage | 2×2；南面两口入，北面两口出。缓冲同一种物品，优先从首个可用出口排出。 | 输送无需接线。东侧脚报库存品种，西侧脚报满仓。吞吐受接入带及上下游限制。 |
| 22/23 地下一阶，24/25 地下二阶 | 偶数为入口（南进），后一个编号为出口（北出）。同级、同旋转、同一直线，沿入口朝向找出口。 | 无线。一对传一带。原版端点坐标距离上限分别为 5、9 格，中间最多隔 4、8 格。 |
| 26 Hub | 4×4，四边共 16 个图形入口，交付、存储并推动目标。西侧有一个当前目标图形输出脚。 | 交付无需接线；信号可用于换型。固定建筑。 |
| 33 拉杆 lever | 无物流端口；北侧信号脚输出布尔开关。 | 放在 regular 层，电线层读输出。 |
| 37 过滤器 filter | 南进，信号为真或等于物品时从北出，其余从东侧拒绝口出。没有有效网络值时停止接收。 | **需接西侧信号脚**。一台对应一条输入带，保持两个分支可排料。 |
| 40 显示器 display | 无物流口；南侧引脚输入，显示图形、颜色或布尔值。 | 需要可显示的信号。 |
| 49 读带器 reader | 南入北出，物料原样通过。左脚为最后经过的物品，右脚表示近期有流量。 | 输送无需接线，读数时接线。一台一带。 |

## 电路层

信号可为布尔值、颜色或完整图形。空信号与布尔假在过滤器等接收端的效果不同。电路建筑处理信号，产能按逻辑功能计，不占物料带宽。

| 编号与建筑 | 旋转 0° 时的作用和引脚 |
| --- | --- |
| 27–30、52–55 电线 wire | 两组编号为 first、second，每组四种外观由相邻连接决定。同色正交相邻即并网；异色可贴边并行，同一格只能放一个电线层实体。并网以后，多个有效输出值不同时网络报冲突。 |
| 39 电线隧道 wire_tunnel | 两个相对边直通；十字位置的水平、垂直方向可以分别通过，同轴两端按游戏连线规则成网。用于电路交叉。普通十字电线会合网。 |
| 31 常量 constant_signal | 北脚输出配置的颜色、布尔值或图形短码。用 configure 设置。 |
| 32/34/35/36 逻辑门 logic_gate | AND、NOT、XOR、OR。双输入型从西和东取值，NOT 从南取值，均从北输出布尔值。 |
| 38/60 晶体管 transistor | 南侧为数据，西侧为使能（镜像 60 为东侧），真时北侧传数据，否则输出空。 |
| 42 虚拟切割 virtual_processor default | 南入图形，西、东分别出两半图形信号。 |
| 44 虚拟旋转 rotater | 南入，北出顺时针旋转 90° 后的图形信号。 |
| 45 虚拟拆层 unstacker | 南入，西出除顶层外的其余层，东出顶层；单层输入时西端为空。 |
| 50 虚拟堆叠 stacker | 南侧是下方图形，东侧是上方图形，北出堆叠结果。 |
| 51 虚拟上色 painter | 南进图形，东进颜色，北出着色图形。 |
| 43 分析器 analyzer | 南进图形，只看最底层的右上象限；西出颜色，东出由该子形重复四次组成的原色图形。该象限为空则两端为空。 |
| 46 比较器 comparator | 西、东两个有效输入按类型和值比较，北出布尔结果；任一输入为空时输出空。 |

## 特定模式的建筑

| 编号 | 效果与接口 |
| --- | --- |
| 61 item_producer | 南脚读取信号，北口产生相应实物。用于提供该工具的模式。 |
| 62 constant_producer | 配置固定物品后从北口生产，无外部电线输入。 |
| 63 goal_acceptor | 南口接目标图形，记录谜题交付，无产物。 |
| 64 block | 占地障碍，无物料口和引脚。 |

上述特殊建筑以 catalog 的 available 为准。图形短码每层按右上、右下、左下、左上排列，每象限一个形状字符加一个颜色字符，缺角写 `--`；从底到顶以冒号分层。例 `CuCuCuCu` 为原色圆。规划叠层时可先用虚拟建筑验证配方。
